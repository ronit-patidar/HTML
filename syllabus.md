# 🌐 HTML Syllabus (Full Stack Web Development)

## 📌 1. Introduction to HTML

* What is HTML?
* History & importance of HTML
* How browsers render HTML
* Basic structure of HTML document:

  * `<!DOCTYPE html>`
  * `<html>`, `<head>`, `<body>`

---

## 📌 2. HTML Basics

* Tags, Elements, Attributes
* Nesting of elements
* Comments in HTML
* Block vs Inline elements

---

## 📌 3. Text & Formatting

* Headings (`<h1>` to `<h6>`)
* Paragraph (`<p>`)
* Line break (`<br>`)
* Horizontal line (`<hr>`)
* Text formatting:

  * `<b>`, `<strong>`
  * `<i>`, `<em>`
  * `<u>`, `<mark>`
  * `<small>`, `<del>`, `<ins>`

---

## 📌 4. Links & Navigation

* Anchor tag (`<a>`)
* Absolute vs Relative URLs
* Open links in new tab
* Internal page navigation

---

## 📌 5. Images & Multimedia

* Images (`<img>`)

  * `src`, `alt`, `width`, `height`
* Audio (`<audio>`)
* Video (`<video>`)
* Embed content (`<iframe>`)

---

## 📌 6. Lists

* Ordered list (`<ol>`)
* Unordered list (`<ul>`)
* Description list (`<dl>`)
* Nested lists

---

## 📌 7. Tables

* Table structure:

  * `<table>`, `<tr>`, `<td>`, `<th>`
* Table sections:

  * `<thead>`, `<tbody>`, `<tfoot>`
* Attributes:

  * `colspan`, `rowspan`

---

## 📌 8. Forms (Important ⭐)

* `<form>` tag and attributes
* Input types:

  * text, password, email, number
  * radio, checkbox
  * date, file, submit
* `<label>`
* `<select>` and `<option>`
* `<textarea>`
* Form validation:

  * `required`, `pattern`, `placeholder`

---

## 📌 9. Semantic HTML (Important ⭐)

* Why semantic HTML?
* Common semantic tags:

  * `<header>`
  * `<footer>`
  * `<section>`
  * `<article>`
  * `<nav>`
  * `<aside>`
  * `<main>`

---

## 📌 10. HTML5 Features

* New input types (email, date, range, color)
* `<canvas>` (basic introduction)
* `<svg>` (basic introduction)
* `<progress>`, `<meter>`
* Local storage (overview)

---

## 📌 11. SEO Basics

* `<title>` tag
* Meta tags:

  * description
  * keywords
  * viewport
* Proper heading structure

---

## 📌 12. Accessibility (a11y)

* `alt` attribute for images
* ARIA roles (basic)
* Labels for form inputs
* Semantic structure for accessibility

---

## 📌 13. Integration with CSS & JavaScript

* Linking CSS:

  * `<link>`
* Adding JavaScript:

  * `<script>`
* Favicon:

  * `<link rel="icon">`
* Responsive meta tag

---

## 📌 14. Best Practices

* Proper indentation & formatting
* Use semantic tags
* Avoid inline styles
* Write clean and readable code

---

## 🎯 Outcome

After completing this syllabus, you should be able to:

* Build structured web pages
* Create forms and layouts
* Understand semantic and accessible HTML
* Prepare HTML foundation for full stack development
